# 単語帳UIアイコン

正解後の意味確認ボタンの `visibility-rounded.svg` は [Google公式のvisibility](https://github.com/google/material-design-icons/blob/master/symbols/web/visibility/materialsymbolsrounded/visibility_24px.svg)（Material Symbols Rounded、24px、Apache-2.0）を無改変で収録。

「今日の学習」の `bar-chart-rounded.svg`・`schedule-rounded.svg`・`settings-rounded.svg` はGoogle公式リポジトリのMaterial Symbols Rounded（24px）を無改変で収録。既存のApache-2.0ライセンスを適用し、閉じる・回答・完璧のアイコンは既存素材を再利用する。

姉妹アプリの `grid-view-rounded.svg`・`open-in-new-rounded.svg` はGoogle公式の [grid_view](https://github.com/google/material-design-icons/blob/master/symbols/web/grid_view/materialsymbolsrounded/grid_view_24px.svg)・[open_in_new](https://github.com/google/material-design-icons/blob/master/symbols/web/open_in_new/materialsymbolsrounded/open_in_new_24px.svg)（Material Symbols Rounded、24px、Apache-2.0）を無改変で収録。同梱の `close-rounded.svg` を再利用する。

Material Symbols Rounded（Google、Apache-2.0）をIconify経由で使用。承認済みM3Eモックの公式アイコンデータからそのまま抽出。図形は手描き・変更せず、CSS maskで製品色を適用する。

Copyright Google LLC. Apache License 2.0の全文は `Material-Symbols-LICENSE.txt`（同梱のGoogle Materialパッケージにある標準ライセンス文を再利用）。

元データ：`docs/experiments/wordbooks-m3e-2026-10-07/src/components/m3e/icon-data.app.ts` と `icon-data.ts`。

ヘッダーの `refresh-rounded.svg`・`check-circle-rounded.svg`・`auto-awesome-rounded.svg` は [Googleの公式リポジトリ](https://github.com/google/material-design-icons/tree/master/symbols/web) のMaterial Symbols Rounded（24px、weight 400、grade 0）から無改変で収録。キラキラだけfill 1、ほかはfill 0。分類ボタンの本は既存の `menu-book-outline-rounded.svg` を再利用する。

Roboto Flex（ラテン文字）は承認済みモックのFontsourceパッケージから使用。SIL Open Font License 1.1は `Roboto-Flex-LICENSE.txt`。日本語は既存アプリのNoto Sans JPを維持。

意味カードの `question-mark-rounded.svg` は [Google公式のquestion_mark](https://github.com/google/material-design-icons/blob/master/symbols/web/question_mark/materialsymbolsrounded/question_mark_24px.svg)（Material Symbols Rounded、24px）を無改変で収録。ほかのMaterialアイコンと同じApache-2.0ライセンス。
