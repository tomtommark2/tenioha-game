# フレーズ品詞修復・第3回（2026-09-09）

ローカル実装済み・未公開。第2回の分類残件 **lot／most／yeah、3語6行** を修復した。[完全な変更前後と根拠](vocabulary-changes/2026-09-09-phrase-pos-batch-03.json)。

- lot：句全体の働きと単語の品詞を分け、名詞に統一。数量表現の後続名詞まで示す。
- most：「冠」を既存の数量限定詞の分類「形」に揃え、数量の意味を修正。
- yeah：通常の応答を名詞とする表示を修正。Cambridgeの副詞分類を採用。

品詞を変えた4行は `legacyKeyPos` に旧品詞を保持。全13,505原データ行・参照語・統合カードの学習キーが修正前と同じことを確認した。既存の統合済み履歴は再リセットせず、保存版番号・スコア許可リストも変更しない。名詞画像の派生キューは分類修正を反映し4,571キー（画像登録済み100キー）へ更新。

## 表示の修正

例文の用法ボタン列を、品詞とフレーズで選ぶ高さ44pxのネイティブ選択欄に変更。同じ品詞が続いても内容で区別できる。切替後の例文・読み上げ対象を維持する。

- 対象8語：lot、most、yeah、round、last、short、back、apple。
- 幅320／390／768／1280pxでChromiumとWebKit、計64表示を確認。文字・ページの横はみ出しなし。back／appleの画像は正方形比率と画面内配置を確認。
- round／lastの選択欄は旧ボタン列の144px（幅320）／94px（幅390）から44pxへ縮小。これは選択欄自体の比較で、カード全高の差ではない。
- 長文では縦スクロールが必要。画面内に全内容が常に収まる保証ではない。物理スマートフォンの実機検証ではなく、ブラウザーエミュレーション。
- [最新表示一覧](http://localhost:8000/screenshots/compact-example-selector-2026-09-09/index.html)。`before-chromium` は修正後データで旧ボタン配置だけを再現した比較画像であり、旧品詞データの撮影ではない。過去のレビュー画像は当時の証跡として保持。
