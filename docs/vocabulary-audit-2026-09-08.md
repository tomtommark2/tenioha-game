## 結論

単語数の削減より先に、**取り込み漏れ・品詞と教材内容の不一致を修復する**。品詞違いは原則維持し、同じ用法の二重登録と表記違いを整理する。調査のみで、単語データ・アプリ・公開環境は変更していない。

- 主対象: A1–B2の8,018項目、綴りで7,000種類。全8単語帳13,505行の構造・参照も確認。
- 実行データ: `data/vocabulary.js`。比較基準: ルートの `CEFR-J Wordlist Ver1.6 - *_sep.csv` 4ファイル。
- 全件を機械検査し、異常候補の意味・用例を重点確認した。全語・全例文の辞書照合による悉皆監修ではない。

### 内容の重点確認例

- A1 `feed（名）`（7179行）: 訳が「餌をやる」、例文も動詞。名詞の教材へ修復する候補。B1には動詞項目が既にある。
- A1 `excuse（名）`（7161行）: `Excuse me` は動詞用法。名詞の意味・用例を用意する。
- A2 `after（副）`（36行）: `after school` は前置詞用法。副詞カードの用例が前置詞カードと区別できていない。
- A2 `adult（形）`（26行）: `He is an adult now.` は名詞用法。形容詞用例へ修復する。
- A2 `latter（副・代）`（4 / 714行）: 訳・phrase・exampleが同一で、`the latter part` は形容詞用法。元CSVにも副詞タグがあり、出典から再確認する。
- A2 `most（副・代）`（5 / 812行）: 訳・phrase・exampleが同一。代名詞カードとしての内容が不足。
- A1 `yeah（名）`（8026行）: 現在の意味・例文は間投詞用法。A2にも項目があり、品詞・レベルを併せて確認する。
- A1 `its（代）`（7356行）: 「それのもの」と独立所有代名詞のように教える一方、例文は `its tail`。別の限定詞側の項目と整理する候補。
- A1 `all / another / my` 等（6842 / 6859 / 7498行）: 限定詞を「冠」としている。限定詞と形容詞の分類流儀差をすべて誤りとはしないが、冠詞表示は整理対象。

『真・英文法大全』PDF113ページを本文・画像で確認し、前置詞／副詞／接続詞の区別に使用。[Cambridgeのafter解説](https://dictionary.cambridge.org/grammar/british-grammar/after)と照合した。latterは[Cambridgeの辞書項目](https://dictionary.cambridge.org/dictionary/english/latter)も参照。『英語イメージ大図鑑』の after / アフター検索では適切な本文を特定できず、文法の根拠には使っていない。

3語以下の `example` はA1 195/1,221（15.97%）、A2 7/1,448（0.48%）、B1 1,794/2,480（72.34%）、B2 2,721/2,869（94.84%）。短い命令文は正常な場合もあり、これは不良率ではない。`Present situation.` / `Valid passport.` など句だけの教材が多く、品詞別の使い方を見分けられる例文を優先して増やす。

## 「別々に表示するか」「要らない語か」の判断

1. **品詞違いは原則残す。** presentの名詞・動詞・形容詞、fastの形容詞・副詞などは学習内容が異なる。一覧で一見出しにまとめ、用法ごとに展開する表示案がよい。学習履歴の統合とは別の判断。
2. **表記違いは一枚＋別名表示を検討。** a.m. / A.M. / am / AM、午後の4表記、email / e-mail / E-mail、Internet / internet。午前のamとbe動詞のamを混ぜない。color / colour、aluminium / aluminum も英米別綴りとして扱う候補。
3. **同品詞・同じ基本義のレベル間重複は共通本体へ寄せる候補。** 語義が違う場合は残す。綴り＋品詞が同じでも語義・発音の違いを持つ語があるため、一律統合しない。
4. **cassette / fax等を直感だけで削除しない。** 日常で自分が使う優先度と、読解・認識語彙としての価値は別。頻度・利用目的のデータなしに不要ランキングを作らない。

## 比較元にも注意する

基準は [CEFR-J Wordlist Version 1.6](https://www.cefr-j.org/download.html)。公式は同綴りの別品詞を別項目とし、異なるレベルも付けている。公式合計7,801項目に対して、ローカル加工CSVは7,988行。別綴り分離等の粒度差をそのまま「余分な187語」と呼ばない。

加工CSVには `latter=adverb`、`exaggerate=noun` がある。[exaggerateの辞書項目](https://www.merriam-webster.com/dictionary/exaggerate)は動詞であり、アプリをCSVの品詞へ機械的に戻してはいけない。公式ページの説明は確認したが、配布Excelの再取得は失敗しており、その全行との再照合は未実施。

- 発生時点、全語の頻度、学習ログによる効果、全例文・発音の悉皆監修は今回の範囲外。
