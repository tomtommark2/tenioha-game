# 分類欄と学習タイマーの配置

- 対象版：`2026.1027.1107`。公開元main `701ef0b0` から対象UIだけを反映する。
- スマホの分類欄は最大264pxで止め、280px幅でも4列・44px以上の操作幅・4桁の件数を維持する。キャラとイラストの足元は紫／白の境界へ揃える。
- PCは「基礎・学習時間・今日」を上段に並べ、上端と高さ34pxを揃える。スマホの入口配置は保持し、「今日」と時計付きタイマーの角丸を4pxにする。381〜389pxで入口が重なる旧紹介ボタン用の指定を削除する。
- 公開前に関連PC10件・モバイル10件（Chromium／WebKit）、キャッシュ登録単体2件、HTML／版番号同期を確認済み。280〜1280px、境界幅、4桁表示、イラスト、足元、復習球、開閉を含む。280pxで見つかった足元のずれは修正後に両エンジンで再確認した。
- 実際のIABでは旧CSSがキャッシュに残ったため、版番号を更新して表示を確認。公開版も同じ版管理を使う。計測・保存・認証・配点・課金・Firebaseの処理は変更しない。
- 元作業と公開用checkoutの他の未コミット資料は保持し、公開差分へ含めない。公開後の版・配信ファイル一致とPC／スマホの実画面検証を別途記録する。
